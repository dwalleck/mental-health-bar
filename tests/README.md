## Test Strategy

1. **Contract Tests First** - Define API behavior through tests
2. **TDD Workflow** - Red → Green → Refactor
3. **High Coverage Goal** - Target 80%+ code coverage
4. **Fast Feedback** - Unit tests run in milliseconds
5. **Integration Tests** - Verify full stack works together

## Running Tests

```bash
# Run all tests
dotnet test

# Run with code coverage
dotnet test --collect:"Code Coverage"

# Run specific project
dotnet test tests/MentalHealthBar.Api.Tests

# Watch mode
dotnet watch test --project tests/MentalHealthBar.Api.Tests
```
